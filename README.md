# 🎙️ 나만의 AI 회의록 에이전트 웹 사이트 (AI Meeting Minutes)

## 📌 프로젝트 소개
이 프로젝트는 길고 지루한 회의 내용을 자동으로 녹음하고, 텍스트로 바꾸고, 요약까지 해주는 **'똑똑한 AI 회의록 비서'** 웹사이트입니다.

## ✨ 주요 기능
- **메모장 기능:** 회의 중 간단한 메모를 작성할 수 있는 기능
- **음성 녹음 및 변환 (STT):** 마이크로 들어온 회의 음성을 Assembly AI를 통해 텍스트로 변환
- **AI 스마트 요약 및 회의록 생성:** GPT API를 활용하여 수많은 대화 내용을 읽고 핵심만 뽑아 회의록 생성
- **사용자 맞춤 설정 창:** 요약 및 회의록을 만들 때 사용할 프롬프트를 직접 설정할 수 있는 기능
- **자동 저장 및 알림:** Make(웹훅)를 활용해 완성된 회의록을 노션(Notion)에 자동 저장하고, 슬랙(Slack)으로 팀원들에게 알림 전송

## 🛠️ 개발 환경 및 사용된 도구
- **프레임워크:** Next.js
- **에디터:** Cursor
- **음성 인식:** Assembly AI
- **AI 모델:** OpenAI GPT API
- **자동화 툴:** Make (Notion, Slack 연동)
- **배포:** Vercel

## 🚀 시작하는 방법 (실행 방법)
이 프로젝트를 내 컴퓨터에서 실행하려면 아래 순서대로 따라 해 보세요!

1. 먼저 필요한 재료(패키지)들을 설치합니다. (npm 대신 pnpm을 사용합니다)
```bash
pnpm install
```

2. 터미널에 아래 명령어를 입력해서 개발용 서버를 켜주세요.
```bash
pnpm run dev
```

3. 인터넷 창을 열고 `http://localhost:3000` 으로 접속하면 완성!
