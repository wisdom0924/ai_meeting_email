## 1. 제품 개요 (어떤 프로그램을 만드나요?)

### 1.1 목적 (왜 만드나요?)
* **우리가 해결할 문제:** 회의가 끝난 후 누가 무슨 말을 했는지 기억하기 어렵고, 회의록을 직접 타이핑하는 것은 너무 힘들고 귀찮은 일입니다.
* **제공하는 가치:** 버튼 하나만 누르면 AI가 회의 내용을 알아서 듣고, 똑똑하게 글자로 적어주고, 핵심만 딱! 요약해 줍니다. 사용자는 회의록 작성 스트레스에서 벗어나 업무를 훨씬 빠르고 효율적으로 할 수 있습니다.

### 1.2 범위 (어디까지 만드나요?)
* **버전 1.0의 목표:** 인터넷 브라우저(크롬, 사파리 등)에서 바로 접속해서 사용할 수 있는 **웹 사이트 형태**로 만듭니다. 처음에는 복잡한 회원가입이나 로그인 없이 나 혼자서만 사용하는 '단일 사용자' 버전을 목표로 합니다.

### 1.3 대상 사용자 (누가 쓰나요?)
* **주요 사용자:** 회의가 잦은 회사원, 조별 과제를 하는 학생, 인터뷰나 긴 대화를 기록해야 하는 사람들.
* **사용자의 니즈(필요한 것):** "회의 내용을 놓치지 않고 다 기록하고 싶다!", "누가 알아서 회의 내용 좀 요약해 줬으면 좋겠다!"

## 2. 기능 명세 (어떤 기능들이 들어가나요?)

### 2.1 음성 녹음 기능
* **설명:** 컴퓨터 마이크를 통해 회의 목소리를 녹음하는 기능입니다.
* **상세 내용:** 
  * 화면에 있는 🔴 **[녹음 시작]** 버튼을 누르면 녹음이 시작되고, ⏹️ **[녹음 중지]** 버튼을 누르면 끝납니다.
  * 녹음 중에는 현재 몇 분째 녹음하고 있는지(예: `01:23`) 초시계가 보여야 합니다.

### 2.2 메모 입력 기능
* **설명:** 녹음을 하면서 사용자가 직접 중요한 내용을 키보드로 칠 수 있는 기능입니다.
* **상세 내용:** 
  * 녹음이 진행되는 동안 옆에 있는 '메모장' 칸에 글씨를 쓸 수 있습니다.
  * 번뜩이는 아이디어나 꼭 기억해야 할 숙제 같은 것을 잊기 전에 바로바로 적어둘 수 있습니다.

### 2.3 회의 데이터 관리 기능
* **설명:** 만들어진 회의록들을 차곡차곡 모아두고 다시 찾아보는 기능입니다.
* **상세 내용:**
  * 날짜와 회의 제목별로 목록을 보여줍니다. (예: `2026-03-27 주간 회의`)
  * 목록에서 하나를 클릭하면 예전 회의록과 요약 내용을 다시 볼 수 있습니다.
  * 필요 없는 회의록은 🗑️ **[삭제]** 버튼으로 지울 수 있습니다.

### 2.4 AI 기반 회의록/요약 생성 기능
* **설명:** 인공지능이 말소리를 글자로 바꿔주고(회의록), 긴 글을 짧게 줄여주는(요약) 핵심 마법 기능입니다.
* **상세 내용:**
  * **텍스트 변환:** 녹음이 끝나면 인공지능이 음성을 전체 대화 글(텍스트)로 바꿔줍니다.
  * **AI 요약:** 바뀐 전체 글을 바탕으로 "오늘 회의의 핵심 3가지"와 같이 AI가 짧은 요약본을 만들어 줍니다.

### 2.5 설정 관리 기능 (AI 프롬프트 설정)
* **설명:** AI에게 "이렇게 요약해 줘!"라고 똑똑하게 명령을 내릴 수 있는 설정창입니다.
* **상세 내용:**
  * **프롬프트(*설명: AI에게 내리는 지시문 또는 명령문*):** 사용자가 직접 AI에게 내릴 명령을 수정할 수 있습니다.
  * 예시 1 (요약용): "이 회의를 3줄로 핵심만 요약해 줘."
  * 예시 2 (상세 회의록용): "결정된 사항과 앞으로 할 일을 표로 정리해 줘."

### 2.6 데이터 외부 연동 (웹훅) 기능
* **설명:** 완성된 회의록을 다른 업무 프로그램으로 슝~ 하고 보내는 기능입니다.
* **상세 내용:**
  * **웹훅(*설명: 우리 프로그램에서 어떤 일이 끝났을 때, 다른 프로그램으로 신호를 보내주는 우체부 역할*):** 버튼을 누르면 완성된 요약본을 내가 지정한 다른 메신저(슬랙 등)나 메모장으로 자동 전송합니다.

## 3. UI/UX 디자인 고려사항 (화면은 어떻게 생겼나요?)

### 3.1 주요 화면 레이아웃 (화면 배치)
* **헤더 (맨 윗부분):** 프로그램 로고와 이름, 그리고 ⚙️ 설정 버튼이 있습니다.
* **메인 콘텐츠 영역 (가운데 넓은 부분):** 
  * **왼쪽:** 큼직한 녹음 버튼과 타이머가 있고, 그 아래에 직접 글을 쓸 수 있는 메모장이 있습니다.
  * **오른쪽:** AI가 변환해 준 '전체 회의록'과 '핵심 요약' 결과가 크게 보입니다.

### 3.2 필요한 주요 UI 컴포넌트 (화면의 부품들)
* **버튼:** [녹음 시작], [녹음 종료], [요약하기], [외부로 보내기] 등 누르기 쉽게 크고 눈에 띄는 색깔로 만듭니다.
* **텍스트 표시 영역:** 긴 글을 읽기 편하도록 글자 크기를 넉넉하게 하고, 배경은 눈이 편안한 밝은 색으로 합니다.
* **설정 팝업(작은 창):** ⚙️ 버튼을 누르면 화면 가운데에 작은 창이 떠서 AI 명령(프롬프트)을 수정할 수 있게 합니다.

### 3.3 일관된 디자인 시스템 (통일된 꾸미기)
* 프로그램 전체적으로 같은 색깔(예: 메인 색상은 파란색), 같은 글씨체, 같은 모양의 버튼을 사용해서 사용자가 헷갈리지 않고 편안함을 느끼도록 합니다.

## 4. 기술 스택 (어떤 도구로 개발하나요?)

초보자나 주니어 개발자도 쉽게 참여할 수 있도록 인기 있는 도구들을 사용합니다!

* **Next.js (넥스트 제이에스):** 웹사이트의 뼈대와 화면을 아주 빠르고 쉽게 만들어주는 최신 도구(웹 프레임워크)입니다.
* **Tailwind CSS (테일윈드 씨에스에스):** 화면을 예쁘게 꾸밀 때 쓰는 도구입니다. 복잡하게 코드를 짜지 않고도 레고 블록 맞추듯 쉽게 색깔과 크기를 정할 수 있습니다.
* **Assembly AI (어셈블리 에이아이):** 사람의 목소리를 듣고 글자(텍스트)로 똑똑하게 바꿔주는(STT) 마법의 외부 인공지능 서비스입니다.
* **GPT:** 글을 읽고 아주 똑똑하게 요약해 주거나 정리해 주는 뇌 역할을 하는 유명한 인공지능 모델입니다.
* **로컬 저장 (Local Storage):** 서버라는 큰 창고를 빌리지 않고, 사용자가 접속한 인터넷 브라우저(크롬 등) 안에 데이터를 일기장처럼 몰래 저장해 두는 간단한 방법입니다.
* **패키지 매니저:** 우리는 npm 대신 더 빠르고 효율적인 **pnpm**을 사용합니다!

* **검증 가능성:** 여기에 적힌 모든 기능은 나중에 "진짜로 녹음 버튼을 누르면 녹음이 되나요?"라고 테스트해서 확인할 수 있어야 합니다.
* **이해관계자 검토:** 개발자, 디자이너 등 모든 팀원이 이 문서를 읽고 "이해했어요!" 하고 동의해야 개발을 시작할 수 있습니다.
