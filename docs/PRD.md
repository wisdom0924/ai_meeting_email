> **최종 수정일:** 2026-05-27
> **작성자:** PM (Product Manager)
> **검토 필요 부서:** 개발, 디자인, QA, 마케팅 (모두 함께 읽고 확인해 주세요!)

---

## 1. 제품 개요 (어떤 프로그램을 만드나요?)

### 1.1 목적 (왜 만드나요?)
* **우리가 해결할 문제:** 회의가 끝난 후 누가 무슨 말을 했는지 기억하기 어렵고, 회의록을 직접 타이핑하는 것은 너무 힘들고 귀찮은 일입니다.
* **제공하는 가치:** 버튼 하나만 누르면 AI가 회의 내용을 알아서 듣고, 똑똑하게 글자로 적어주고, 핵심만 딱! 요약해 줍니다. 사용자는 회의록 작성 스트레스에서 벗어나 업무를 훨씬 빠르고 효율적으로 할 수 있습니다.

### 1.2 범위 (어디까지 만드나요?)
* **버전 1.2의 목표:** 인터넷 브라우저(크롬, 사파리 등)에서 바로 접속해서 사용할 수 있는 **웹 사이트 형태**로 만듭니다. 회원가입과 로그인을 통해 **나만의 데이터**를 클라우드에 안전하게 보관하고 언제든 다시 열어볼 수 있도록 개선했습니다.

### 1.3 대상 사용자 (누가 쓰나요?)
* **주요 사용자:** 회의가 잦은 회사원, 조별 과제를 하는 학생, 인터뷰나 긴 대화를 기록해야 하는 사람들.
* **사용자의 니즈(필요한 것):** "회의 내용을 놓치지 않고 다 기록하고 싶다!", "누가 알아서 회의 내용 좀 요약해 줬으면 좋겠다!", "어디서든 내 회의록을 다시 찾아보고 싶다!"

## 2. 기능 명세 (어떤 기능들이 들어가나요?)

### 2.1 회원가입 및 로그인 기능 (신규/개선)
* **설명:** 나만의 일기장처럼 내 회의록만 볼 수 있게 열쇠를 채우는 기능입니다.
* **상세 내용:** 
  * 이메일 주소와 닉네임으로 회원가입하고 로그인할 수 있습니다. (자체 데이터베이스 사용)
  * **이메일 인증 기능:** 가입 시 입력한 이메일로 인증 메일을 보내고, 인증이 완료되어야만 로그인이 가능하도록 보안을 강화했습니다.
  * 로그인 및 가입 진행 중에는 로딩 스피너(모래시계)가 표시되어 진행 상태를 알 수 있습니다.

### 2.2 음성 녹음 및 파일 업로드 기능
* **설명:** 컴퓨터 마이크를 통해 회의 목소리를 녹음하거나, 핸드폰으로 미리 녹음해둔 파일을 올리는 기능입니다.
* **상세 내용:** 
  * 🔴 **[녹음 시작]** / ⏹️ **[녹음 중지]** 버튼으로 실시간 녹음을 할 수 있습니다. (진행 시간이 초시계로 보입니다.)
  * 이미 가지고 있는 '오디오 파일'을 화면에 업로드해서 AI에게 분석을 시킬 수도 있습니다.

### 2.3 메모 입력 기능
* **설명:** 녹음을 하면서 사용자가 직접 중요한 내용을 키보드로 칠 수 있는 기능입니다.
* **상세 내용:** 
  * 녹음이 진행되는 동안 옆에 있는 '메모장' 칸에 중요한 단어나 할 일을 잊기 전에 바로 적어둘 수 있습니다.

### 2.4 회의 데이터 클라우드 관리 기능 (업그레이드)
* **설명:** 만들어진 회의록과 녹음 파일을 안전한 서버(FastAPI)와 창고(MySQL)에 차곡차곡 모아두는 기능입니다.
* **상세 내용:**
  * 로그인한 나만 볼 수 있도록 나만의 '히스토리(기록)' 목록을 만들어줍니다.
  * 예전 회의록을 클릭하면 AI가 요약했던 내용도 그대로 다시 볼 수 있습니다.

### 2.5 AI 기반 회의록/요약 생성 기능
* **설명:** 인공지능이 말소리를 글자로 바꿔주고, 긴 글을 짧게 줄여주는 마법 기능입니다.
* **상세 내용:**
  * **텍스트 변환:** 녹음이 끝나거나 파일을 올리면 AI가 전체 대화 글(텍스트)로 바꿔줍니다.
  * **AI 요약:** "오늘 회의 핵심 3가지"와 같이 짧은 요약본을 만들어 주고, 내가 직접 요약된 글의 줄바꿈이나 띄어쓰기를 수정할 수도 있습니다.

### 2.6 이메일 및 외부 연동 기능 (신규/개선)
* **설명:** 완성된 회의록을 다른 사람에게 편지로 슝~ 보내는 기능입니다.
* **상세 내용:**
  * 화면에서 버튼을 누르면 완성된 요약본을 동료의 이메일로 바로 보낼 수 있습니다.
  * 내가 자주 보내는 이메일 주소는 프로그램이 기억해두었다가 자동완성으로 추천해 줍니다.
  * Make 웹훅을 통해 노션이나 슬랙 등 다른 프로그램으로도 보낼 수 있습니다.

### 2.7 설정 관리 기능 (AI 프롬프트 설정)
* **설명:** AI에게 "이렇게 요약해 줘!"라고 똑똑하게 명령을 내릴 수 있는 설정창입니다.
* **상세 내용:**
  * 사용자가 직접 AI에게 내릴 명령을 수정할 수 있습니다. (예: "결정된 사항과 앞으로 할 일을 표로 정리해 줘.")

## 3. UI/UX 디자인 고려사항 (화면은 어떻게 생겼나요?)

### 3.1 주요 화면 레이아웃 (화면 배치)
* **헤더 (맨 윗부분):** 프로그램 로고와 ⚙️ 설정 버튼, 로그인/로그아웃 상태가 있습니다.
* **메인 콘텐츠 영역 (가운데 넓은 부분):** 
  * **왼쪽:** 큼직한 녹음/업로드 영역과 메모장이 있습니다.
  * **오른쪽:** AI가 만들어준 '전체 회의록'과 '핵심 요약' 영역을 탭으로 나눠서 깔끔하게 볼 수 있습니다.

### 3.2 필요한 주요 UI 컴포넌트 (화면의 부품들)
* **버튼:** [녹음], [파일 올리기], [이메일 보내기] 등 누르기 쉬운 큼직한 크기로 만듭니다.
* **텍스트 영역:** 요약된 글을 직접 수정할 때 글자가 깨지지 않고 예쁘게 줄이 맞춰지도록 합니다.

## 4. 기술 스택 (어떤 도구로 개발하나요?)

초등학생도 이해할 수 있게 설명하자면, 우리가 집을 지을 때 쓰는 망치나 벽돌 같은 도구들입니다!

* **Next.js (넥스트 제이에스):** 웹사이트의 예쁜 화면을 만들어주는 도구입니다. (식당의 홀 역할)
* **FastAPI (패스트 에이피아이):** 보이지 않는 곳에서 어려운 계산과 주문을 처리하는 아주 빠른 파이썬 서버입니다. (식당의 주방 역할)
* **MySQL (마이에스큐엘):** 우리의 소중한 회의록과 회원 정보를 안전하게 보관하는 튼튼한 전용 창고입니다.
* **Docker (도커) & Oracle Cloud (오라클 클라우드):** 우리가 만든 프로그램을 네모난 상자에 포장해서, 24시간 꺼지지 않는 인터넷 땅 위에 올려놓는 기술입니다.
* **Assembly AI & Gemini:** 목소리를 글자로 적어주고 요약해주는 똑똑한 인공지능 비서들입니다.
* **패키지 매니저:** 우리는 npm 대신 더 빠르고 효율적인 **pnpm**을 사용합니다!

* **버전 관리:** 내용이 바뀌면 맨 위에 있는 '문서 버전'을 올려서 언제 무엇이 바뀌었는지 모두가 알 수 있게 합니다.
